      Google DeepMind toolkit

        MongoDB Atlas features

          Argon API rules to follow

          • Use the Interactions API: client.interactions.create. SDK google-genai>=2.3.0 or @google/genai@latest.
          • Set thinking_level to "low", "medium" (default) or "high". Don't use thinking_budget.
          • Remove temperature, top_p, top_k and explicit cached_content. Caching is implicit.
          • Set background=True to generate past 65,536 tokens, up to 1M.
          • Pathway 1 agents: thinking_level medium or high, long decode in background, or run inside antigravity-preview-09-2026.

          What sinks a project

          • A chat wrapper or Q&A bot over a single PDF.
          • A static page with no autonomous reasoning, verification loop or multimodal workflow.
          • Medical, mental-health or financial advice without a human in the loop.
          • Code written before kickoff. Starter templates are fine; the demo must show hackathon code.
          • A demo that needs slides or runs past 3 minutes.
          Scores are my rough estimates to help you choose, not predictions. Every "who" is a role: before the demo, replace it with a real person you can name and have spoken to.
