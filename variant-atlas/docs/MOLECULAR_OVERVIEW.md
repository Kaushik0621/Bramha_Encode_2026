# Molecular overview: structure → evidence → project

Implemented on Home only. Project routing, source tables, scientific forms, calculations and the investigation chamber retain their existing workflows. The supplied brief references a recording, but no recording was supplied with it; visual direction follows the written brief, without a claim of matching unseen footage.

## Composition and interaction

One authentic PTEN subject occupies the hero's visual column beside editorial typography. A visible Resume project action remains available above the fold. The sidebar still provides direct Home, Projects, Sources and Investigations access. The existing research dashboard follows the two-section experience.

A single Mol* `PluginContext` spans both chapters. Native scroll progress drives its presentation wrapper, a modest camera rotation, evidence-heading reveal and selection styling. The molecule clears the evidence column early in the transition. Reverse scrolling uses the same canonical camera snapshot and progress mapping, without accumulated rotation. The interactive evidence card stays positionally stable; heading travel does not move click targets.

The evidence focus highlights canonical C124, mapped to chain A / label residue 118. The card uses `PTEN:p.C124S` from `/api/workspaces/pten-real`, including the actual activity and abundance values on their separate native scales. It does not clamp or normalize the displayed measurements, infer a causal mechanism, or show a changed mutant fold. Source links open the shared canonical source detail pages.

“Inspect evidence” and the variant link pass exact variant, reference accession, dataset and mapping versions into a supported PTEN project. With no PTEN project, they open the project picker and retain this context through explicit project creation. The destination checks versions before selecting the substitution, waits for the saved project scene to restore, then records the selection in the existing journal. A mismatched version produces an explicit notice and preserves the saved scene. No project or investigation is created merely by entering or scrolling Home.

## Performance and accessibility

The headless Mol* adapter is lazy loaded. Navigation, text and actions appear before it is ready. One viewer is disposed when leaving Home. Device pixel ratio is capped at 1.5 via Mol*'s pixel scale. Animation loops pause when the actual scene leaves the viewport or the tab is hidden. Scroll and pointer changes use a requestAnimationFrame scheduler and refs/DOM properties, without per-frame React state updates. Pointer tilt is bounded on the presentation wrapper and disabled on mobile and for reduced motion.

Desktop uses a short sticky scene across two content-bearing sections, without scroll interception or waiting periods. Mobile stacks text, one scene and the evidence card, with no sticky scene or pointer response. Reduced motion removes entrance travel, parallax and scroll rotation; focus styling changes immediately. The scene is passive; essential actions remain ordinary keyboard-accessible links outside the canvas. WebGL failure or context loss exposes the lightweight trace and preserves evidence, provenance and navigation. Mol*'s separate canvas-readiness promise rejection is consumed when initialization fails, preventing an uncaught browser rejection while the fallback renders.

Mol* remains a large lazy dependency. This change does not claim a small viewer download or measured performance on all mobile GPUs. No new animation library, video sequence or rendering stack was added.

## Argon configuration and actual verification

The user-supplied credential is stored only as `GOOGLE_API_KEY` in the ignored backend `.env`, permissions `0600`. `LLM_PROVIDER=google` selects Google for contextual planning; research execution and paper reading use the Google key when configured. Existing OpenRouter credentials are retained; errors do not silently become OpenRouter or fixture success.

The official Google model catalogue accepted the key and listed `gemini-4-argon`. Two small structured-action checks requested medium thinking and background execution through the installed SDK. The first returned `RateLimitError`; the later recheck reached its explicit 90-second deadline (`TimeoutError`). Successful generation and scientific execution are therefore **not verified**. The sanitized evidence is [ARGON_CONNECTIVITY.json](../artifacts/ARGON_CONNECTIVITY.json). No clinical or full autonomous research success is implied by catalogue access. No Google Live model or Atlas connection was configured as a consequence of adding this key.
